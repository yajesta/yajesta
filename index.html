Northants Event Solutions

Rushden · Live

Nene Valley Bathrooms and Kitchens

Rushden · In progress

A multi-page site I'm building for a bathroom, kitchen and renovation company in Rushden, Northamptonshire. It is not public yet, so there is no link.

The site is organised around the work they do — bathrooms, kitchens, boilers and heating, and building and renovations — with further pages for their story, how a project runs, finance, inspiration and contact. An enquiry form asks for a name, phone number, email and a note about the project, and offers a free design consultation. The finance pages explain the options and link out to a calculator.

UI kit

Live

@oscarkalid/ui is a set of React components and the design tokens they are built on — buttons, tables, dialogs, charts and the smaller pieces around them.

You can install the package and import the stylesheet, or copy a single component file into a project and change it. Everything visual comes from CSS variables, with raw values and a semantic layer on top. The documentation has installation notes, a page for each component, icon and logo sets, and a markdown version of every page for use with language models.
