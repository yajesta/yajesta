UI kit

@oscarkalid/ui is a set of React components and the design tokens they are built on. Install the package, or copy a component in and change it.

ui.oscarkalid.com (opens in a new tab)

I wanted interface pieces I could reuse, with the colours and type kept in tokens instead of copied from one project to the next.

The kit is React components, one file each. You can install the package, or take a file and change it. The notes for it are on ui.oscarkalid.com, covering buttons, fields, tables, dialogs and the smaller parts around them.

What I can do for you

I make new websites for local businesses, and I redesign ones that no longer match the work. I can also look after hosting, and the updates that come up once a site is live.

If you need customers to get in touch, I add an enquiry form that sends the message to you by email.

How I work

  1. First chat

    We talk about the business, who the site is for, and what it needs to do.

  2. Design

    I design the pages so you can see the type, the colour and how it moves before the rest is filled in.

  3. Build

    I build the site with you, and check it on a phone and on a larger screen.

  4. Launch and aftercare

    I put it online, then stay for hosting and the changes that come later.

About me

I'm based in Northamptonshire. I build websites for local businesses through Northants Web Solutions, from the first conversation through to launch.

I also design and build my own UI kit. It is the components and tokens I use when an interface needs to be made carefully and used again.

I like motion that belongs to one system: the same ease and the same length of time, so nothing on the page jumps.
