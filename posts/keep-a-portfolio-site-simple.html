Keep a portfolio site simple

17 Nov 2026

I redid oscarkalid.com to be a simple site for my work and games. The useful parts were not new ideas. They were decisions I had to keep making, one page at a time.

Separate pages, clean URLs

Use separate pages with clean URLs. This site has Work, Games, Tools, Posts, and About, each at its own address: /, /games, /tools, /posts, and /about. That is easier to send someone than a long page and a request to scroll. It also means each page can be short, because it does not have to hold everything.

Cut the filler

If a sentence does not add a fact, take it out. Short descriptions are enough. On Work, the Northants Event Solutions site is a title, a link, and a screenshot. Nene Valley Bathrooms and Kitchens is a title and a screenshot, because that site is still in progress. You can see the work without a paragraph about my process.

Make the details match

Links on this site use a dotted underline. The section headings on About match each other. Dates and short meta lines use the same muted style. None of that is interesting on its own. It becomes noticeable when it is broken: one solid underline, one heavier heading, one date in a different colour. Pick the details once and use them everywhere.

Keep the motion small. The tabs and page changes on this site have a short, quiet transition. That is enough to make the change feel intended. A larger effect would get in the way of reading. If you cannot tell what a transition is for, it is decoration, and you can remove it.

Live numbers, where they would go stale

On the Games page, visits and favourites for Become a Trillionaire and Clear The Snow update while you look at them. A figure I typed in last month would already be wrong. If a number changes often, let the page fetch it. If it doesn't, write it once and leave it alone.

One column is enough. A portfolio does not need a grid of cards, a long intro, or a list of adjectives. It needs to be easy to read, easy to scan, and easy to open on a phone. If I am open to new work, that belongs in a plain sentence on About, next to a way to contact me, not in a slogan at the top of every page.

The test is whether you can add a new project or a new post without redesigning anything. A new page in a folder, a new line on the list, the same type and the same details. If that is hard, the site is doing too much.
